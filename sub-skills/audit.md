# Channel Audit

Run a channel audit across four independent dimensions: packaging/SEO, performance funnel, content strategy, and monetisation. If private analytics are unavailable, clearly mark public-only analysis.

## Inputs
Channel URL/handle, niche, channel stage, goal, and date range. Do not ask for details already provided.

## Workflow
1. Inspect channel positioning, About section, recent uploads, playlists and visible metadata.
2. Gather channel/video metrics from YouTube API or user-provided Studio exports where available.
3. Evaluate packaging (title/thumbnail promise), topic selection, format consistency, audience promise, upload cadence and discoverability.
4. Analyse funnel metrics only when supplied: impressions → CTR → views; retention → watch time; returning viewers; traffic sources; conversions.
5. Identify monetisation fit and risk, including originality/reused-content concerns.
6. Prioritise findings by impact, evidence and effort.

## Output
Executive diagnosis; scorecard with evidence; top 5 strengths; top 5 bottlenecks; 30-day action plan; metrics to monitor; confidence and data limitations. Never infer private CTR, retention or revenue from public views.
