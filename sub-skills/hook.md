# Hook Generator

Generate 5 materially different hooks: curiosity gap, problem/stakes, demonstration-first, story, and contrarian/evidence. Each must identify the viewer, problem, payoff and proof opportunity.

Score each on clarity, specificity, stakes, curiosity, credibility, and title alignment. Use bundled hookscore.py when available. Scores are diagnostics, not predictions. Return best 2, explain tradeoffs, and recommend one. Avoid greetings, channel intros and generic claims.
