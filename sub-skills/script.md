# Retention-Engineered Script

Use the approved brief, target audience, voice profile and evidence. Confirm the title promise within the opening. Build a clear progression: hook → stakes → proof → steps/chapters → payoff → CTA.

For each beat provide narration, visual, on-screen text, proof/artifact, and transition. Introduce pattern interrupts only when they clarify or reset attention, typically every 45–90 seconds depending on format. Avoid filler, fake suspense, repetitive summaries and unsupported claims. Include source notes for factual claims. Estimate runtime from word count and stated narration rate. Finish with a self-review: promise fulfilled, pacing, clarity, originality, visuals and factuality.
