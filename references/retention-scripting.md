# Retention Scripting Playbook

## Structure
Hook → promise/context → proof → progressive value → payoff → CTA/next video.

## Hook principles
- Start with the viewer's problem, surprising result, demonstration or stakes.
- Confirm the title promise quickly.
- Avoid greetings, long credentials and generic channel intros.
- Create curiosity that the video actually resolves.

## Body
- One main idea per beat.
- Every beat advances the question, shows evidence, teaches a useful step or creates a meaningful transition.
- Use examples, screen demonstrations, contrast, visual changes and story only when they improve comprehension.
- Remove repeated points, filler and fake suspense.
- Pattern interrupts are not a timer requirement; use them when attention or comprehension needs a reset.

## End
Deliver the promised payoff, recap only what helps, and offer a relevant next video or CTA. Review for title-promise mismatch, unsupported claims and pacing.
