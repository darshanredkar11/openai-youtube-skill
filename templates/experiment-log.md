# YouTube experiment log

Keep one entry per meaningful test. Record what changed so wins and losses can teach the next decision.

| Date | Video / test | Hypothesis | Change | Primary metric | Baseline | Result | Decision / learning |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## Rules
- Change one major variable at a time where practical.
- Define the metric and observation window before publishing.
- Do not call a result from a tiny sample.
- Separate distribution noise from evidence about the content.
- Record unsuccessful experiments; do not rewrite history after the result.
